# Bmax artist guide

Bmax adds tools for sculpting, rigging, UV inspection and everyday scene work to Blender 5.2.3 LTS. This guide focuses on what you can do and where to find it.

[Download Bmax for Windows](https://maxpuliero.gumroad.com/l/bmax) · [What's new](whats-new.md) · [Report a bug](https://github.com/MaxPuliero/Bmax/issues)

## Before you start

Download and extract the complete Windows package, then launch **blender.exe** from that folder. Keep the accompanying folders with the executable.

This guide describes the current Bmax features. Your downloaded version may include fewer features; check the download's release notes. The latest changes listed under **What's new** have not yet been added to the public Windows package.

Bmax uses Blender 5.2 preferences and startup settings. Menu names in this guide use the English interface.

## Getting help

Choose **Help > Report a Bmax Bug**. Describe what you were doing, what you expected and what happened. A screenshot or a small example file helps. If possible, mention whether the same issue happens in official Blender.
