# What's new in Bmax

[Artist guide](README.md) · [Download](https://maxpuliero.gumroad.com/l/bmax)

These are the latest improvements in Bmax development. They are planned for the next public Windows package; check the download's release notes before expecting them in your installed version.

## November 9, 2026 — Clearer UV editing

- Shell outlines stay beneath UV edges, selected and unselected vertices, and pin markers.
- Pins stay visible in Edge and Face modes.
- Pin, Unpin and Invert Pins work directly with selected edges and faces.

[UV editing guide](uv.md)

## November 7, 2026 — More control over sculpting and color

- Repeat Last Stroke builds up the last geometry stroke with the **1** shortcut.
- Symmetrize Blend averages matching sides, respects masks and can blend painted color.
- Multires Color Filter supports all ten color filter modes.
- Color sampling reads the painted Multires color correctly after subdivision and level changes.

[Sculpting and painting guide](sculpt.md)

## November 5, 2026 — Brush depth limits

- Capture a Persistent Base and control outward/inward brush movement separately.
- Keep the reference through brush Undo and changes between Object and Sculpt Mode.
- Clear the reference with Flush Persistent.

[Sculpting and painting guide](sculpt.md)

## November 4, 2026 — Smoother everyday work

- Organize Quick Favorites from Preferences or the Q menu.
- Carry your 3D view between workspaces while retaining each workspace's shading.
- Create a compatible project copy with Save as Official.
- Apply supported property edits to the selection without an Alt exception.

[Interface guide](interface.md) · [Saving and compatibility](compatibility.md)
